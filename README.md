# MongoDB CRUD Operations

This project demonstrates basic MongoDB CRUD operations using JavaScript.

## Features

- Create documents
- Read documents
- Update documents
- Delete documents
- Aggregation examples

## Files Included

- `01_setup.mongodb.js` → Database setup and sample data
- `02_Reading.mongodb.js` → Read operations
- `03_Update.mongodb.js` → Update operations
- `04_Delete.mongodb.js` → Delete operations
- `05_Aggregations.mongodb.js` → Aggregation queries

## Technologies Used

- MongoDB
- JavaScript
- Mongo Shell

## Sample Collections

### Products
Contains:
- Product name
- Price
- Category
- Stock
- Ratings
- Tags

### Contacts
Contains:
- Name
- Message
- Phone number
- Created date

## How to Run

1. Open MongoDB Shell
2. Run the JavaScript files
